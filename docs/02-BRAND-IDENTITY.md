# 02 — IDENTITÉ DE MARQUE

## Signes

- **Nom** : 5DEV — toujours en capitales, le « 5 » en noir, « DEV » en orange.
- **Signature** : BUILD. INNOVATE. GROW.
- **Positionnement** : studio digital de Matadi, sérieux dans l’exécution, direct dans le discours.

## Couleurs (officielles, non négociables)

| Rôle | Valeur | Usage |
|---|---|---|
| Orange 5DEV | `#F47721` | accent, boutons, liens, chiffres clés, mots d’emphase |
| Blanc | `#FFFFFF` | fond principal, respiration |
| Noir | `#171717` | texte, sections inversées, pied de page |
| Gris texte secondaire | `#6B6B6B` | descriptions, métadonnées |
| Ligne | `#E6E2DD` | séparateurs, bordures de cartes |
| Lavis | `#FAF8F5` | fonds alternés de section |

Règles : l’orange ne sert jamais de fond sur de grandes surfaces (lisibilité) ; jamais plus de
deux accents orange par écran ; le noir `#171717` est la seule couleur de texte principale.

## Typographie

- **Titres** : sans-serif géométrique, graisse 900, interlettrage serré (−0,03 em).
- **Texte** : sans-serif, 16–18 px, interligne 1,6.
- **Étiquettes / métadonnées** : monospace, capitales, interlettrage large (0,28 em).

## Ton

Phrases courtes. Pas de superlatifs (« leader », « n°1 », « révolutionnaire »). On décrit ce
qui est livré, avec des verbes d’action. Aucun chiffre non vérifiable, aucun témoignage inventé.

## Interdits visuels

- Photos de stock génériques présentées comme des réalisations 5DEV.
- Dégradés multicolores, effets « glassmorphism » gratuits.
- Icônes de packs différents mélangés (une seule famille : Lucide).
- Texte sur photo sans voile de contraste suffisant.
